📱 Analytics API Reference

Universal Telemetry Ingestion & Real-Time Query Infrastructure

🌐 Live Production API Endpoint

All telemetry ingestion and analytics reporting requests should be routed to the live endpoint below:

Base URL: https://wild-bush-1cd7.trustconnect713.workers.dev/

⚡ Cross-Platform Support

The Analytics API is completely platform-agnostic. It accepts standard HTTPS JSON requests from any client environment, allowing you to stream telemetry seamlessly across multiple platforms using a single unified backend:

Android (Kotlin / Java) Web Apps (JavaScript / TypeScript) HarmonyOS (ArkTS) iOS (Swift) Cloudflare Workers / Server Backends Flutter & React Native
💡 Note on Client Implementation: The REST API is completely language-agnostic. The code snippets provided in this documentation are non-binding sample references demonstrating how to format HTTP request payloads. Developers are free to implement their own HTTP client logic, queuing mechanisms, or wrapper libraries in any programming language or framework.

1. Cross-Platform Sample Integrations

A. Web Integration Sample (JavaScript / Browser Fetch)

async function sendWebTelemetry(eventName, customProps = {}) {
  await fetch("https://wild-bush-1cd7.trustconnect713.workers.dev/", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      app_id: window.location.hostname, // e.g., "chyke.online"
      api_key: "live_sdk_key_9988",
      device: {
        os: "Web",
        os_version: navigator.platform,
        app_version: "1.0.0"
      },
      events: [
        {
          type: "custom",
          name: eventName,
          timestamp: Math.floor(Date.now() / 1000),
          properties: customProps
        }
      ]
    })
  });
}

// Example Trigger
sendWebTelemetry("page_view", { path: "/articles", referrer: "google" });

B. Android Integration Sample (Kotlin)

// Initialize once in Application class
MyAnalyticsSDK.initialize(
    context = this,
    apiKey = "live_sdk_key_9988",

MyAnalyticsSDK.trackEvent(

2. REST API Endpoint Specifications

Ingest Analytics Data (POST /)

Send single or batched system and custom telemetry events. Returns an immediate HTTP 202 Accepted response while queuing records into KV storage asynchronously.

Endpoint: POST https://wild-bush-1cd7.trustconnect713.workers.dev/

Header: Content-Type: application/json

Request Payload:

{
  "app_id": "com.atzec.app",
  "api_key": "live_sdk_key_9988",
  "device": {
    "os": "Android",
    "os_version": "14",
    "app_version": "2.1.0"
  },
  "events": [
    {
      "type": "default",
      "name": "app_start",
      "timestamp": 1785862000,
      "properties": { "launch_time_ms": 350 }
    },
    {
      "type": "custom",
      "name": "level_completed",
      "timestamp": 1785862050,
      "properties": { "level": 5, "score": 12500 }
    }
  ]
}

cURL Command Example:

curl -X POST "https://wild-bush-1cd7.trustconnect713.workers.dev/" \
  -H "Content-Type: application/json" \
  -d '{
    "app_id": "com.atzec.app",
    "api_key": "live_sdk_key_9988",
    "device": { "os": "Android", "os_version": "14", "app_version": "2.1.0" },
    "events": [
      { "type": "custom", "name": "button_click", "timestamp": 1785862000, "properties": { "target": "play_btn" } }
    ]
  }'

Success Response (HTTP 202):

{
  "success": true,
  "queued": 2
}

Endpoint: GET https://wild-bush-1cd7.trustconnect713.workers.dev/?app_id=com.atzec.app&limit=50
