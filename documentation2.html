Connectgold Mobile Mediation SDK Integration Guide

Connectgold is a high-yield mobile ad mediation engine powered by Cloudflare Workers. Developers integrate Connectgold's SDK and adapters to run real-time unified SDK mediation auctions, combining direct Paystack advertiser campaigns and 30 integrated mobile ad networks optimized via Cloudflare Workers AI Gateway ("connectgold-gateway").

How Connectgold Edge Bidding Works:
  • Unified Endpoint Request: Your app requests /?platform=android&format=banner&pub_id=... to fetch real-time ad parameters and optimized network mediation waterfalls.
  • AI Yield Optimization: Mobile waterfalls are dynamically evaluated using Cloudflare Workers AI (`@cf/google/gemma-4-26b-a4b-it`) routed through the `connectgold-gateway` AI Gateway instance.
  • Dynamic Reflection Engine: For local SDK fallback, the SDK uses Class.forName to dynamically discover and instantiate installed network adapters from a real-time waterfall payload.
  • Zero Crashing (Graceful Failover): Unused SDK dependencies catch ClassNotFoundException automatically and seamlessly route to available networks or fallback tags.

Edge Data Flow Diagram

[ Mobile App / Mediation Request ] │ ▼ [ Connectgold Cloudflare Worker ] ── (AI Optimization via Gemma 4 / Gateway) │ ├──► [ Direct KV Campaigns ] ── (Paystack Funded Balance) └──► [ 30 Network Waterfall ] ── (Local Reflection Adapters) │ ▼ [ Highest eCPM Bid Returned & Rendered ]

1Gradle Setup (`app/build.gradle`)

Add the Connectgold Core SDK (which includes Connectgold's personal ad network adapter and all 30 built-in mediation adapter classes). Then, add official Gradle dependencies for any partner networks you wish to include in local reflection mediation:

dependencies { // 1. Core Connectgold Mobile SDK (Includes Mediation Engine + 30 Integrated Network Adapters) implementation 'com.connectgold.sdk:connectgold-core:1.0.0' // 2. Add Partner Network SDKs from the 30-Network Matrix to enable local reflection implementation 'com.yandex.android:mobileads:X.Y.Z' // Yandex Ads implementation 'com.google.android.gms:play-services-ads:X.Y.Z' // Google AdMob implementation 'com.unity3d.ads:unity-ads:X.Y.Z' // Unity Ads implementation 'com.ironsource.sdk:mediationsdk:X.Y.Z' // ironSource implementation 'com.inmobi.monetization:inmobi-ads-kotlin:X.Y.Z' // InMobi implementation 'com.startapp:inapp-sdk:X.Y.Z' // Start.io }

2Android Manifest Configuration

Ensure required network permissions are declared in AndroidManifest.xml to allow Connectgold to execute edge auctions and render ad creatives programmatically.

Getting Your Publisher ID: Sign in to the Connectgold Dashboard Console and navigate to the App Credentials tab to copy your unique pub_id string.
<manifest xmlns:android="http://schemas.android.com/apk/res/android"> <!-- Required Internet & Network State Permissions --> <uses-permission android:name="android.permission.INTERNET" /> <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" /> <application> <!-- CONNECTGOLD PUBLISHER ID --> <meta-data android:name="com.connectgold.sdk.PUBLISHER_ID" android:value="YOUR_PUB_ID_FROM_DASHBOARD" /> </application> </manifest>

3Format-Specific Java Implementation Guide

Programmatic UI layouts are constructed directly in Java. Request ad markup and mediation waterfall configurations from your Cloudflare Worker endpoint using simple GET query parameters:

A. Banner Ad (Programmatic FrameLayout Container)

Banners return responsive ad creatives or a `View` object added programmatically to a container layout:

FrameLayout bannerContainer = new FrameLayout(this); setContentView(bannerContainer); String bannerUrl = "https://royal-thunder-8246.trustconnect713.workers.dev/?platform=android&format=banner&pub_id=YOUR_PUB_ID_FROM_DASHBOARD"; ConnectgoldMediation.fetchAndLoad(this, bannerUrl, new AdLoadListener() { @Override public void onAdLoaded(String networkName, Object adView) { if (adView instanceof android.view.View) { bannerContainer.removeAllViews(); bannerContainer.addView((android.view.View) adView); } } @Override public void onAdFailedToLoad(String reason) { Log.e("Connectgold", "Banner load failed: " + reason); } });

B. Fullscreen Interstitial Ad

Interstitials load in memory and display over the current Activity upon winning auction selection:

String interstitialUrl = "https://royal-thunder-8246.trustconnect713.workers.dev/?platform=android&format=interstitial&pub_id=YOUR_PUB_ID_FROM_DASHBOARD"; ConnectgoldMediation.fetchAndLoad(this, interstitialUrl, new AdLoadListener() { @Override public void onAdLoaded(String networkName, Object adObject) { Log.d("Connectgold", "Interstitial ready from: " + networkName); ConnectgoldMediation.showAd(MainActivity.this, adObject); } @Override public void onAdFailedToLoad(String reason) { Log.e("Connectgold", "Interstitial failed: " + reason); } });

C. Rewarded Video Ad (With User Reward Callback)

Rewarded ads trigger completion callbacks when video playback finishes:

String rewardedUrl = "https://royal-thunder-8246.trustconnect713.workers.dev/?platform=android&format=rewarded&pub_id=YOUR_PUB_ID_FROM_DASHBOARD"; ConnectgoldMediation.fetchAndLoad(this, rewardedUrl, new AdLoadListener() { @Override public void onAdLoaded(String networkName, Object adObject) { ConnectgoldMediation.showRewardedAd(MainActivity.this, adObject, new RewardListener() { @Override public void onUserRewarded(String rewardType, int amount) { Log.d("Connectgold", "Reward earned: " + amount + " " + rewardType); grantInAppCoins(amount); } }); } @Override public void onAdFailedToLoad(String reason) { Log.e("Connectgold", "Rewarded video failed: " + reason); } });

D. Native Ad (Dynamic Card Binding)

Native ads return structured components (Headline, Image, Body, CTA) bound directly to Java UI elements:

String nativeUrl = "https://royal-thunder-8246.trustconnect713.workers.dev/?platform=android&format=native&pub_id=YOUR_PUB_ID_FROM_DASHBOARD"; ConnectgoldMediation.fetchAndLoad(this, nativeUrl, new AdLoadListener() { @Override public void onAdLoaded(String networkName, Object nativeAdObj) { ConnectgoldNativeAd nativeAd = (ConnectgoldNativeAd) nativeAdObj; TextView titleView = new TextView(MainActivity.this); titleView.setText(nativeAd.getTitle()); Button ctaButton = new Button(MainActivity.this); ctaButton.setText(nativeAd.getCtaText()); ctaButton.setOnClickListener(v -> nativeAd.performClick()); LinearLayout nativeLayout = new LinearLayout(MainActivity.this); nativeLayout.setOrientation(LinearLayout.VERTICAL); nativeLayout.addView(titleView); nativeLayout.addView(ctaButton); setContentView(nativeLayout); } @Override public void onAdFailedToLoad(String reason) { Log.e("Connectgold", "Native ad failed: " + reason); } });

E. VAST Video Stream XML

For custom player implementations (ExoPlayer / MediaPlayer), retrieve raw VAST streams by specifying `format=vast`:

String vastUrl = "https://royal-thunder-8246.trustconnect713.workers.dev/?platform=android&format=vast&pub_id=YOUR_PUB_ID_FROM_DASHBOARD"; ConnectgoldMediation.fetchVastStream(this, vastUrl, new VastStreamListener() { @Override public void onVastReady(String vastXmlUrl) { exoPlayer.setMediaItem(MediaItem.fromUri(vastXmlUrl)); exoPlayer.prepare(); } @Override public void onVastFailed(String error) { Log.e("Connectgold", "VAST stream failed: " + error); } });

4Writing Custom Mediation Adapters

Developers can extend Connectgold mediation by implementing the ConnectgoldAdapter interface:

Step A: Define the Adapter Interface

package com.connectgold.sdk.adapters; import android.content.Context; import org.json.JSONObject; public interface ConnectgoldAdapter { interface Listener { void onSuccess(String networkName, Object adView); void onFailure(String errorReason); } void loadAd(Context context, JSONObject params, Listener listener); }

Step B: Sample Custom Adapter Implementation

package com.yourcompany.app.adapters; import android.content.Context; import org.json.JSONObject; import com.connectgold.sdk.adapters.ConnectgoldAdapter; public class CustomAdNetworkAdapter implements ConnectgoldAdapter { @Override public void loadAd(Context context, JSONObject params, Listener listener) { String placementId = params.optString("placement_id"); String appId = params.optString("app_id"); ThirdPartySDK.requestAd(context, appId, placementId, new ThirdPartySDK.Callback() { @Override public void onAdReady(Object view) { listener.onSuccess("CustomAdNetwork", view); } @Override public void onError(String error) { listener.onFailure(error); } }); } }

7Third-Party Analytics Integration (Optional)

⚠️ Setup Notice:

Configure tracking credentials inside the 📊 Analytics Settings tab on your Connectgold Dashboard.

Connecting third-party analytics is completely optional. You can pass credentials dynamically via HTTP headers or append parameter query keys (ga4_id, plausible_domain, mixpanel_token) directly to your ad URL query string:

Optional Analytics Query Example (Java)

String adUrlWithAnalytics = "https://royal-thunder-8246.trustconnect713.workers.dev/" + "?platform=android&format=interstitial" + "&pub_id=YOUR_PUB_ID_FROM_DASHBOARD" + "&ga4_id=G-XXXXXXXXXX" + "&plausible_domain=chyke.online" + "&mixpanel_token=361e...a28e"; ConnectgoldMediation.fetchAndLoad(this, adUrlWithAnalytics, new AdLoadListener() { @Override public void onAdLoaded(String networkName, Object adObject) { ConnectgoldMediation.showAd(MainActivity.this, adObject); } @Override public void onAdFailedToLoad(String reason) { Log.e("Connectgold", "Ad load failed: " + reason); } });

8GDPR, EEA & Regional Privacy Consent

Pass regional user consent status in your worker request parameters:

  • &consent=1 : User granted consent for personalized ads.
  • &consent=0 : User denied consent (Serves non-personalized fallback ads).
