ConnectGold Mediation SDK - Official Developer Guide

Official integration manual for publishers implementing the ConnectGold Mobile Ad Mediation SDK into Android applications.

Mediation Endpoint: https://old-term-8a97.trustconnect713.workers.dev/v1/mediate
app-ads.txt Endpoint: https://old-term-8a97.trustconnect713.workers.dev/app-ads.txt

1. Executive Overview

The ConnectGold Edge Mediation SDK dynamically evaluates ad requests through edge computing nodes. It routes requests across 30 ad networks using real-time waterfall logic to maximize fill rates and eCPM performance.

2. System Requirements & ProGuard Rules

  • Minimum SDK Version: Android 5.0 (API Level 21) or higher
  • Target/Compile SDK Version: Android 14 (API Level 34) or higher
  • Java Version: Java 11 or Java 17 toolchains
  • Gradle Version: 7.0+

ProGuard / R8 Rules (proguard-rules.pro)

Because ConnectGold uses Reflection to dynamically load network adapters, add these rules to preserve class paths during release builds:

# Preserve ConnectGold Mediation Engine & Adapters
-keep class com.connectgold.ads.mediation.** { *; }
-keep class com.connectgold.ads.adapters.** { *; }
-keep interface com.connectgold.ads.mediation.MediationAdapter { *; }

# Preserve Google Advertising ID & Media3 ExoPlayer
-keep class com.google.android.gms.ads.identifier.** { *; }
-keep class androidx.media3.** { *; }

4. SDK Initialization

Java Initialization (Java)

package com.connectgold.ads;

import android.content.Context;
import android.util.Log;

public class ConnectGoldSDK {
    private static final String TAG = "ConnectGoldSDK";
    private static boolean isInitialized = false;

    public interface InitCallback {
        void onSuccess();
        void onError(String error);
    }

    public static void initialize(Context context, String appId, InitCallback callback) {
        if (isInitialized) {
            if (callback != null) callback.onSuccess();
            return;
        }

        try {
            Log.i(TAG, "Initializing ConnectGold SDK with App ID: " + appId);
            isInitialized = true;
            if (callback != null) callback.onSuccess();
        } catch (Exception e) {
            Log.e(TAG, "SDK Initialization Failed", e);
            if (callback != null) callback.onError(e.getMessage());
        }
    }
}

Kotlin Initialization (Kotlin)

package com.connectgold.ads

import android.content.Context
import android.util.Log

object ConnectGoldSDK {
    private const val TAG = "ConnectGoldSDK"
    var isInitialized: Boolean = false
        private set

    fun initialize(context: Context, appId: String, onComplete: ((Boolean, String?) -> Unit)? = null) {
        if (isInitialized) {
            onComplete?.invoke(true, null)
            return
        }

        try {
            Log.i(TAG, "Initializing ConnectGold SDK with App ID: $appId")
            isInitialized = true
            onComplete?.invoke(true, null)
        } catch (e: Exception) {
            Log.e(TAG, "SDK Initialization Failed", e)
            onComplete?.invoke(false, e.message)
        }
    }
}

XML Layout Setup (XML)

<FrameLayout
    android:id="@+id/banner_ad_container"
    android:layout_width="320dp"
    android:layout_height="50dp"
    android:layout_gravity="center_horizontal" />

Java Implementation (Java)

// XML Container Integration
FrameLayout container = findViewById(R.id.banner_ad_container);
ConnectGoldCore.fetchWaterfall("user_101", "main_banner", "BANNER", new ConnectGoldCore.WaterfallCallback() {
    @Override
    public void onSuccess(JSONArray waterfall) {
        runBannerSequence(waterfall, 0, container);
    }
    @Override
    public void onError(String error) { Log.e("Banner", error); }
});

// Programmatic Container Creation (No XML)
FrameLayout programmaticContainer = new FrameLayout(this);
programmaticContainer.setLayoutParams(new ViewGroup.LayoutParams(320, 50));

10. VAST Video Player Integration

XML Layout (XML)

<androidx.media3.ui.PlayerView
    android:id="@+id/player_view"
    android:layout_width="match_parent"
    android:layout_height="match_parent" />

Java Implementation (Java)

PlayerView playerView = findViewById(R.id.player_view);

ConnectGoldCore.fetchWaterfall("user_101", "preroll_midroll_suite", "VAST", new ConnectGoldCore.WaterfallCallback() {
    @Override
    public void onSuccess(JSONArray waterfall) {
        String vastTagUri = "https://pubads.g.doubleclick.net/gampad/ads?sz=640x480&iu=/12431908/external/single_ad_samples&ciu_szs=300x250&impl=s&gdfp_req=1&env=vp&output=vast&unviewed_position_start=1";
        
        ExoPlayer player = new ExoPlayer.Builder(context).build();
        ImaAdsLoader adsLoader = new ImaAdsLoader.Builder(context).build();
        
        adsLoader.setPlayer(player);
        playerView.setPlayer(player);
        
        MediaItem mediaItem = new MediaItem.Builder()
            .setUri("https://storage.googleapis.com/gte-site-media/sample_content.mp4")
            .setAdsConfiguration(new MediaItem.AdsConfiguration.Builder(Uri.parse(vastTagUri)).build())
            .build();
            
        player.setMediaItem(mediaItem);
        player.prepare();
        player.setPlayWhenReady(true);
    }
    @Override
    public void onError(String error) { Log.e("VAST", error); }
});
