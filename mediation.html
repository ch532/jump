ConnectGold Mediation SDK - Full Reference Manual

Comprehensive technical manual for integrating and operating the ConnectGold Mobile Ad Mediation SDK on Android.

1. Executive Overview

The ConnectGold Edge Mediation SDK routes requests through Cloudflare Workers edge nodes. It uses dynamic waterfall ordering via AI processing (`@cf/google/gemma-7b-it`) and KV configurations to select optimized ad network adapters per user request.

2. Integration & Permissions

3. SDK Initialization & Configuration

Call the initialize method early during application startup (e.g. in Application.onCreate or primary Activity.onCreate).

Java SDK Initialization (Java)

package com.connectgold.ads;

import android.content.Context;
import android.util.Log;

public class ConnectGoldSDK {
    private static final String TAG = "ConnectGoldSDK";
    private static boolean isInitialized = false;

    public interface InitCallback {
        void onSuccess();
        void onError(String error);
    }

    public static void initialize(Context context, String appId, InitCallback callback) {
        if (isInitialized) {
            if (callback != null) callback.onSuccess();
            return;
        }

        try {
            Log.i(TAG, "Initializing ConnectGold Mediation Engine for App: " + appId);
            // Pre-warm network connection & internal parameters
            isInitialized = true;
            if (callback != null) callback.onSuccess();
        } catch (Exception e) {
            Log.e(TAG, "ConnectGold SDK Initialization Failed", e);
            if (callback != null) callback.onError(e.getMessage());
        }
    }

    public static boolean isInitialized() { return isInitialized; }
}

6. Ad Format Implementations

Compact Universal Adapter Iteration Strategy

private void runWaterfall(JSONArray sequence, int index, String format) {
    if (index >= sequence.length()) {
        Log.e("Mediation", "Waterfall exhausted for format: " + format);
        return;
    }

    try {
        JSONObject item = sequence.getJSONObject(index);
        String classPath = item.getString("android_class_path");

        Class<?> clazz = Class.forName(classPath);
        Object adapter = clazz.newInstance();
        Log.i("Mediation", "Successfully instantiated: " + item.getString("adapter_name"));

    } catch (Exception e) {
        // Skip to next ad network adapter on failure
        runWaterfall(sequence, index + 1, format);
    }
}

7. VAST Video Player Integration

Java Media3 ExoPlayer VAST Player (Java)

package com.connectgold.ads;

import android.net.Uri;
import android.os.Bundle;
import androidx.appcompat.app.AppCompatActivity;
import androidx.media3.common.MediaItem;
import androidx.media3.exoplayer.ExoPlayer;
import androidx.media3.exoplayer.ima.ImaAdsLoader;
import androidx.media3.exoplayer.source.DefaultMediaSourceFactory;
import androidx.media3.ui.PlayerView;
import org.json.JSONArray;

public class VastPlayerActivity extends AppCompatActivity {

    private PlayerView playerView;
    private ExoPlayer player;
    private ImaAdsLoader adsLoader;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        
        playerView = new PlayerView(this);
        setContentView(playerView);

        ConnectGoldCore.fetchWaterfall("user_101", "preroll_midroll_suite", "VAST", new ConnectGoldCore.WaterfallCallback() {
            @Override
            public void onSuccess(JSONArray waterfall) {
                String vastTagUri = "https://pubads.g.doubleclick.net/gampad/ads?sz=640x480&iu=/12431908/external/single_ad_samples&ciu_szs=300x250&impl=s&gdfp_req=1&env=vp&output=vast&unviewed_position_start=1";
                initializePlayer(vastTagUri);
            }

            @Override
            public void onError(String message) {
                initializePlayer(null);
            }
        });
    }

    private void initializePlayer(String vastTagUri) {
        ExoPlayer.Builder playerBuilder = new ExoPlayer.Builder(this);

        if (vastTagUri != null) {
            adsLoader = new ImaAdsLoader.Builder(this).build();
            DefaultMediaSourceFactory mediaSourceFactory = new DefaultMediaSourceFactory(this)
                    .setLocalAdInsertionComponents(unused -> adsLoader, playerView);
            playerBuilder.setMediaSourceFactory(mediaSourceFactory);
        }

        player = playerBuilder.build();
        playerView.setPlayer(player);

        Uri videoUri = Uri.parse("https://storage.googleapis.com/gte-site-media/sample_content.mp4");
        MediaItem.Builder mediaItemBuilder = new MediaItem.Builder().setUri(videoUri);

        if (vastTagUri != null) {
            adsLoader.setPlayer(player);
            mediaItemBuilder.setAdsConfiguration(
                new MediaItem.AdsConfiguration.Builder(Uri.parse(vastTagUri)).build()
            );
        }

        player.setMediaItem(mediaItemBuilder.build());
        player.prepare();
        player.setPlayWhenReady(true);
    }

    @Override
    protected void onDestroy() {
        super.onDestroy();
        if (adsLoader != null) adsLoader.release();
        if (player != null) player.release();
    }
}

9. Error Codes & Diagnostics

Error Code Description Troubleshooting Action
ERR_PREMIUM_USER User possesses premium ad-free status. No ads should render. Safe return state.
ERR_WATERFALL_EMPTY Server returned an empty adapter list. Verify placement ID in Cloudflare KV store.
ERR_CLASS_NOT_FOUND Adapter class not compiled into APK. Include missing dependency signature in build.gradle.
ERR_NO_FILL All waterfall networks failed to fill ad. Check ad placement statuses across network dashboards.
ERR_TIMEOUT Network load timeout exceeded limit. Worker automatically falls back to next adapter.
