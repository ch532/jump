Analytics Platform Privacy Policy

Effective Date: August 4, 2026

This Privacy Policy explains how our general-purpose Analytics Platform collects, processes, and stores application telemetry and performance metrics across integrated applications, websites, and connected services.

1. Scope of the Platform

Our analytics infrastructure operates as a multi-application telemetry engine. It accepts event payloads and health metrics sent via API endpoints from mobile apps, web applications, and software services managed under platform-registered application IDs (app_id).

2. Telemetry & Data Collected

Our platform collects non-personally identifiable technical telemetry strictly for aggregation, system diagnostic, and performance reporting purposes:

  • Application Identifiers: Registered platform package names, domain keys, or unique app_id strings.
  • Environment & Device Metadata: Client platform/OS type, system build version, and app release version.
  • Automated System Metrics: Session initialization, startup duration, page or screen views, system state changes, and runtime error counts.
  • Custom Application Telemetry: Developer-configured metrics, feature interactions, and custom user action events passed via standard API payloads.

3. Data Handling & Security Principles

  • No Sensitive PII: The platform does not collect, track, or require Personally Identifiable Information (PII) such as full legal names, passwords, sensitive financial details, or precise GPS location records.
  • Encryption in Transit: All ingested metrics and query API requests are transmitted securely over TLS/HTTPS protocols.
  • Automatic Lifecycle Expiry: Event logs ingested into global key-value database storage are retained for a maximum duration of 90 days, after which they automatically expire and are deleted.

4. Platform Data Rights & Usage

Aggregated metrics are processed solely to provide app performance dashboards, analytics reports, and stability insights to authorized platform users. We do not sell or trade raw telemetry data to external third-party advertisers or data brokers.

5. Contact & Support

For administrative questions or platform compliance requests regarding API usage, please consult your developer console support resources.
