Privacy Policy for Ember AS

Effective Date: August 10, 2026

Summary: Ember AS is a non-custodial, client-side encrypted Bitcoin wallet software and browser extension. We do not collect, store, sell, or transmit your private keys, seed phrases, PINs, or personally identifiable data to any external server.

1. Data Collection and Usage

Ember AS is engineered around a local-first, zero-data collection architecture:

  • No Personal Data Collection: We do not ask for or record your name, email address, IP address, or phone number.
  • Local Key Encryption: All key derivation (BIP-84 Native SegWit) and cryptographic operations occur entirely inside your local client environment. Private keys and Wallet Import Format (WIF) payloads are encrypted locally using AES-256-GCM.
  • No Tracking or Analytics: We do not deploy third-party analytics, tracking scripts, or telemetry code within the browser extension or web interface.

2. Extension Permissions Disclosures

To deliver non-custodial wallet functionality, Ember AS requires the following minimal browser permissions:

  • storage: Strictly used to persist encrypted wallet payloads and user UI preferences locally on your browser.
  • activeTab: Strictly used to allow the wallet provider interface to interact with active dApps for signing PSBT transactions upon your explicit action.
  • host permissions: Strictly used to query public Bitcoin network nodes for balance verification and to broadcast signed transactions.

3. Remote Code Execution

In accordance with extension store security policies, Ember AS does not load or execute remote JavaScript or WebAssembly files. All extension code is statically bundled within the installed extension package.

4. Data Sharing & Third Parties

Because we do not collect any user data, we do not sell, rent, trade, or share any personal information with third parties, marketing agencies, or analytics platforms under any circumstances.

5. Blockchain Transactions

When you broadcast a transaction using Ember AS, the signed payload is submitted to the public Bitcoin blockchain. Public blockchain records are immutable and globally accessible by nature.

6. Changes to This Privacy Policy

We may update this Privacy Policy from time to time to reflect ongoing compliance requirements. Any updates will be published directly to this page.

7. Contact Us

If you have any questions or security inquiries regarding Ember AS, please visit our official website at https://www.chyke.online/ember.
